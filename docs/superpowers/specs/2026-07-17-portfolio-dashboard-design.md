# Relife 投资组合仪表盘设计

## 目标

基于仓库中的美股 TradingView 全量交易记录和银河证券 A 股交割单，生成一个仅所有者可访问的静态 Sites 仪表盘。A 股与美股完全隔离核算，分别展示账户概览、现金流调整收益走势、基准对比、策略分组持仓、倒序交易记录和股息记录。

首版以每日收盘数据为准，不展示盘中实时行情，不在人民币和美元之间做汇率换算或跨市场合计。

## 使用与发布

- 采用 Python 预处理、静态前端展示、Sites 私有部署。
- 数据更新任务自动选择仓库中最新的：
  - `data/tradingview/tradingview_full_latest_*.csv`
  - `data/transactions/yinhe/交割单_*.csv`
- 本地刷新命令完成 CSV 解析、行情下载、组合计算、JSON 生成和生产构建；发布时由 Codex Sites 将同一构建版本部署为仅所有者可访问。
- 站点不提供 CSV 上传、登录、数据库或服务端动态行情请求。
- 构建产物只包含界面所需的标准化数据，不包含原始券商文件。

## 数据处理与计算

### 数据归一化

- 美股支持 `Buy`、`Sell`、`Dividend`、`Deposit`，保留佣金和原始成交时间。
- A 股保留证券买卖、银证转账、利息、逆回购、红利等流水；同日没有时分秒时按源文件顺序稳定排序。
- 所有交易记录默认按成交时间倒序显示，并支持全部、买入、卖出、股息、资金筛选。
- 当前持仓数量按全部买卖累计；剩余成本按含买入费用的移动加权平均法计算。卖出时以扣除卖出费用后的净回款减去卖出前平均成本，确认已实现收益。

### 行情

- 美股持仓和 `QQQ`、`SPY` 使用 Yahoo Finance 日线。
- A 股证券、上证指数和沪深 300 使用 AkShare 日线；证券代码按沪深市场规则映射。
- 最新价统一定义为“最后收盘价”，不使用盘中价格。
- 非交易日向前使用最近有效收盘价；单个历史缺口可以前向填充至下一有效价格。
- 当前持仓若始终取不到行情，数据生成直接失败并列出标的，避免用错误价格发布。
- 页面显式展示每个市场的行情截止日期；行情不是当日时显示“数据截至”提示。

### 账户与收益曲线

- 每个市场独立维护现金、证券市值和总资产。
- 美股现金由入金、买卖、佣金和股息逐笔重建。
- A 股现金优先采用交割单记录的日终 `资金余额`，无流水日延续前值。
- 组合收益曲线使用日频现金流调整收益：外部入金和出金不计为投资收益；内部证券买卖、佣金、利息和股息计入账户表现。
- 组合与基准均在所选区间首个共同有效交易日归一化为 100。
- 默认展示全部交易历史，并提供 1 月、3 月、今年、全部切换。
- A 股当前空仓时仍展示历史收益曲线和现金 100% 状态。

### 持仓字段

默认顺序如下，除“标的”固定外，其他列均可拖拽排序和显示/隐藏：

1. 标的
2. 数量
3. 占总组合比例
4. 总成本
5. 最后收盘价
6. 总现价
7. 每日收益
8. 每日收益%
9. 未实现收益
10. 未实现收益%
11. 组合贡献%
12. 总收益
13. 总收益%

计算口径：

- 占总组合比例 = 当前市值 ÷ 当前市场账户总资产。
- 总成本 = 当前剩余持仓数量 × 含买入费用的移动加权平均成本。
- 总现价 = 当前持仓数量 × 最后收盘价。
- 每日收益 = 当前持仓数量 ×（最后收盘价 − 前一交易日收盘价）。
- 每日收益% = 每日收益 ÷ 前一交易日持仓市值。
- 未实现收益 = 总现价 − 总成本。
- 未实现收益% = 未实现收益 ÷ 总成本。
- 组合贡献% = 未实现收益 ÷ 当前市场账户总资产。
- 总收益 = 已实现收益 + 未实现收益 + 净股息。买入费用已进入成本，卖出费用已从已实现收益扣除，不重复减费。
- 总收益% = 总收益 ÷ 该标的累计买入成本（含买入费用）。

分母为 0 时百分比显示 `—`。列设置通过持仓表右上角的图标打开，面板默认关闭；顺序和可见性保存在浏览器本地，同一设备上的 A 股和美股共用配置，并可恢复默认。

### 策略分组

分组来自 `docs/trading-strategy/交易策略-v1.0.md`，使用独立配置维护映射，不把标的列表硬编码进界面：

- 现金流：现金、`BOXX`
- 大盘：`QQQ`、中证 1000 ETF
- 股息：`XQQI`、`QQQI`、`SCHD`、港股红利
- 个股：防御、进攻
- 杠杆：半导体、中国、纳指
- 比特币：`IBIT`
- 其他：未匹配的持仓，标记“策略外”

分组只负责展示与识别，不自动执行策略配置或再平衡。策略外标的不隐藏；当前样本中的 `XBI` 归入“其他”。

### 股息

- 每个市场独立展示累计净股息、按月净股息柱状图和逐笔明细。
- 美股同日同标的的正股息与负税费调整合并为一笔，展示股息、税费调整和净额。
- A 股 `红利入账` 使用交割单金额作为净额；源文件没有拆分税费时显示 `—`。
- 股息明细默认按日期倒序，并可从交易记录的“股息”筛选进入。

## 界面

- 视觉采用中性炭黑背景，不使用偏蓝背景；组合主线可使用蓝色，基准使用其他高区分度颜色。
- 收益颜色统一采用中国习惯：红涨、绿跌。
- 顶部使用 A 股 / 美股主切换；首次打开默认美股，之后恢复本设备上次选择。
- 市场内包含四个页面：
  - 概览：总资产、累计收益、未实现收益、现金，以及组合与两个基准的收益走势图。
  - 持仓：按策略类别分组的可配置数据表。
  - 交易记录：默认倒序的全量记录和类型筛选。
  - 股息：累计净股息、月度分布和明细。
- 桌面端保持专业数据表密度；小屏端允许持仓表横向滚动，并固定标的列。
- 所有图标按钮提供可访问名称；键盘用户可以打开列设置、切换页面和改变列可见性。拖拽之外同时提供键盘可用的上移/下移操作。

## 失败与边界

- CSV 表头或数值格式异常时，生成任务失败并指出文件、行和字段。
- 美股 TradingView 全量文件作为已去重的权威输入，逐行保留；A 股优先使用成交编号和合同编号识别重复行，编号缺失时使用完整原始行指纹，不合并真实的同日同价分笔成交。
- 行情下载失败时保留上一次成功生成的数据文件，但不得覆盖为不完整版本。
- 页面无持仓、无股息或无某类交易时显示明确空状态。
- 原始交易数据、Sites 项目标识和用户现有未提交文件不得被清理或覆盖。
