# VS Code 观察列表与策略通知设计

## 目标

将 Relife Portfolio 升级到 0.3.0：在现有 Activity Bar 侧栏中维护仓库共享的观察分组，并在预置布林下轨规则触发时发送 VS Code 与可选飞书通知。

## 结构

- `portfolio_viewer/data/watchlist.json` 是观察分组、标的和布林参数的唯一配置源，与持仓分类配置分离。
- Python 检查器复用现有 Yahoo/AKShare 行情类，聚合日、周、月收盘价并输出结构化 JSON，不生成订单。
- 扩展宿主负责四个既有定时点、手动检查、侧栏编辑、去重、SecretStorage 和通知投递。

## 行为

- 最近收盘价低于最近 N 个周期的总体标准差下轨时生成候选事件。
- 候选事件按市场、标的、周期、周期桶和规则参数去重；同一桶只弹窗一次。
- 飞书失败消息保留为待投递并在下一次检查时重试；未配置飞书时只弹出 VS Code 通知。
- 观察配置写入前完整校验并原子替换；单个行情失败不阻断其他标的。

## 边界

- 仅在 VS Code 打开 Relife 工作区时运行，不补发关闭期间的历史信号。
- 不实现通用公式、自动交易、通知历史页面、后台服务或新增第三方依赖。
- Webhook 与签名密钥只保存在 VS Code SecretStorage，不进入仓库或 VSIX。
